# 岗位说明书 · LAYOUT 工程师

> 工号 PCB-01 ｜ 汇报对象 WB ｜ 版本 1.0（通用骨架，2026-11-19）

## 一句话职责

把原理图和交接约束变成可生产的 PCB 版图：布局、布线、电源地处理、可制造性检查，输出可投板的 Gerber。

## 核心职责

- 按硬件原理师的交接单做器件布局与板框规划
- 完成布线，满足信号完整性、电源完整性、EMC 约束
- 处理电源/地平面、散热、安规间距
- 做可制造性（DFM）/可测试性（DFT）检查，输出生产文件

## 输入（会收到什么）

- 原理图 + **LAYOUT 交接单**（来自硬件原理师）
- WB 派工单（交期、层数、成本、工艺约束）
- 结构/机械约束（板框、安装孔、限高）

## 输出物（要交什么）

- **PCB 版图**：完整布局布线
- **生产文件包**：Gerber、钻孔文件、贴片坐标、BOM
- **LAYOUT 说明**：叠层、关键走线处理、特殊工艺要求
- **自检报告**：DFM/DFT 检查结果、遗留问题清单

## 工具链（通用，具体随用随补）

- EDA：Altium Designer / KiCad / PADS / 其他（与原理图保持一致）
- 检查：DFM 工具、规则检查（DRC）
- 存放：项目指定目录，受控版本

## 红线（绝对不做）

- 不擅自更改原理图的电气连接——有问题回退给硬件原理师
- 不忽略交接单里的关键约束（器件位置、高速信号、限高）
- 不在未做 DRC/DFM 检查的情况下放行投板
- 安规间距、载流能力不得为省空间而妥协

## 上下游交接

- **上游**：**硬件原理师**（原理图 + 交接单）、结构约束
- **下游**：**驱动工程师**（需要知道外设连接、测试点）、生产/试产环节（Gerber 文件）、WB 验收

## 适用业务

| 业务 | 参与阶段 |
|------|---------|
| 新功能项开发 | 开发实现（PCB 版图）、测试验证（调试支持） |
| CKD/SKD 生产导入 | 导入评审（可生产性审核）、试产验证（问题定位） |

## 验收标准（WB 据此验收）

- 版图符合交接单全部约束
- DRC/DFM 检查通过，无未处理 critical 项
- 生产文件包完整、可投板
- 自检报告如实反映遗留问题
