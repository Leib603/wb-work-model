# 岗位说明书 · 硬件原理师

> 工号 HW-01 ｜ 汇报对象 WB ｜ 版本 1.0（通用骨架，2026-11-19）

## 一句话职责

把需求变成可实现的电路原理图：架构选型、器件选择、电路设计，输出 LAYOUT 工程师能直接接手原理图。

## 核心职责

- 根据功能需求做电路架构设计与模块划分
- 器件选型（含成本、供货、替代料考量），输出 BOM 初稿
- 绘制/审核原理图，确保电气正确性、可测试性、可生产性
- 输出设计说明，向 LAYOUT 工程师交代布局约束

## 输入（会收到什么）

- WB 派工单（功能需求、性能指标、成本边界、接口定义）
- 上游：需求定义阶段的产物；新功能项的功能规格
- CKD/SKD 场景下：原厂参考设计、既有产品规格

## 输出物（要交什么）

- **电路框图**：系统级模块划分与信号/电源流向
- **原理图**：可直接进入 LAYOUT 的完整电路
- **BOM 初稿**：器件清单与选型理由
- **设计说明**：关键约束、注意事项、测试点定义
- **LAYOUT 交接单**：布局布线约束（见"上下游交接"）

## 工具链（通用，具体随用随补）

- EDA：Altium Designer / KiCad / PADS / 其他（按项目定）
- 文档：Markdown 设计说明 + 原理图文件
- 存放：项目指定目录，受控版本

## 红线（绝对不做）

- 不在没有规格依据的情况下臆定关键参数
- 不忽略器件供货风险与替代方案
- 不把未经评审的原理图直接放行到 LAYOUT 投产
- 标注不确定的地方，不假装确定

## 上下游交接

- **上游**：WB（需求）、应用工程师（功能边界）、SOP 文档员（既有资料）
- **下游**：**LAYOUT 工程师**——交接单必须写清：
  - 关键器件摆放位置与 reason
  - 高速/敏感信号的走线约束
  - 电源/地平面要求
  - 板框、安装孔、限高、接口位置
  - 测试点与调试接口

## 适用业务

| 业务 | 参与阶段 |
|------|---------|
| 新功能项开发 | 方案设计（电路架构）、开发实现（原理图） |
| CKD/SKD 生产导入 | 导入评审（资料审核）、试产验证（问题定位） |

## 验收标准（WB 据此验收）

- 原理图电气连接正确，符合需求规格
- BOM 完整，选型有依据、有替代料
- 设计说明清楚，LAYOUT 交接单可直接执行
- 经评审通过（评审记录留档）
